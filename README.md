# Hi there, I'm Mathenge 👋

I'm a Computer Science student at Strathmore University building full-stack and AI-powered systems, with a particular pull toward applying machine learning to problems in African healthcare, agriculture, and infrastructure. I like taking a system from a rough idea to something that actually runs in production, and I enjoy the debugging grind as much as the design work.

- 🔭 **Current Focus:** Building a two-surface investment management platform (public site + internal committee dashboard) with Next.js, Supabase, and Recharts
- 🌱 **Learning & Exploring:** Applied ML for real-world constraint-heavy environments — anomaly detection, edge AI (OpenVINO), and AI systems for urban infrastructure problems
- ⚡ **Core Interests:** AI/ML for healthcare & agriculture, full-stack web development, embedded/IoT systems, computer vision
- 🏆 **Also into:** Hackathons and competitive ideation — I like building fast, demo-able prototypes under pressure

## Selected Projects

**🔍 AI-Powered Facial Recognition Platform** — Django REST Framework · OpenCV · DeepFace/ArcFace
Full-stack facial recognition system supporting real-time identification across images, video uploads, and live webcam streams. Built intelligent embedding caching and model preloading that boosted recognition performance by 90%+, and resolved concurrency and cross-platform production issues.

**📱 Digital Road Accident Insurance Claims Platform** — React Native · Node.js · Express.js · MongoDB
Cross-platform mobile app that digitized the insurance claims process end-to-end — secure accident reporting, document uploads, real-time claim tracking — with JWT auth and role-based access control.

**🌱 Remote Greenhouse Monitoring System** — IoT/Embedded Systems
Team-built remote monitoring system for carnation greenhouses, deployed for a working farm in Naivasha, Kenya, as part of a university embedded systems course.

**🏥 AI Anomaly Detection for Remote Patient Monitoring** — Django · TimescaleDB · Isolation Forest · React
Research-driven system design for detecting health anomalies in hypertension/diabetes patients in resource-constrained settings, using Isolation Forest on time-series vitals with a real-time alerting pipeline.
